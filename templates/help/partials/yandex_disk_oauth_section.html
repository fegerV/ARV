{{ "1. Create an OAuth application" if is_en else "1. Создайте OAuth-приложение" }}

  1. {% if is_en %}Open https://oauth.yandex.ru/client/new.{% else %}Откройте https://oauth.yandex.ru/client/new.{% endif %}
  2. {% if is_en %}Create a server-side OAuth application for your organization account.{% else %}Создайте серверное OAuth-приложение для учётной записи организации.{% endif %}
  3. {% if is_en %}Save it and copy the Client ID and Client Secret.{% else %}Сохраните его и скопируйте Client ID и Client Secret.{% endif %}

{{ "2. Configure the server" if is_en else "2. Настройте сервер" }}

{% if is_en %}Set the OAuth credentials in the backend environment and restart the app.{% else %}Укажите OAuth-данные в переменных окружения backend и перезапустите приложение.{% endif %}

YANDEX_OAUTH_CLIENT_ID — {{ "client ID from Yandex" if is_en else "Client ID из Yandex" }}

YANDEX_OAUTH_CLIENT_SECRET — {{ "client secret from Yandex" if is_en else "Client Secret из Yandex" }}

{% if is_en %}Without these values the connection button cannot generate the authorization link.{% else %}Без этих значений кнопка подключения не сможет сгенерировать ссылку авторизации.{% endif %}

{{ "3. Connect the company" if is_en else "3. Подключите компанию" }}

  1. {% if is_en %}Open Companies in the admin panel and edit the company.{% else %}Откройте Компании в админке и отредактируйте компанию.{% endif %}
  2. {% if is_en %}Select Yandex Disk as the storage provider.{% else %}Выберите Яндекс Диск как хранилище.{% endif %}
  3. {% if is_en %}Click Connect Yandex Disk. The admin panel will open the Yandex authorization page.{% else %}Нажмите Подключить Яндекс Диск. Админка откроет страницу авторизации Yandex.{% endif %}
  4. {% if is_en %}Authorize access for the organization account and copy the verification code from Yandex.{% else %}Разрешите доступ под учётной записью организации и скопируйте код подтверждения из Yandex.{% endif %}
  5. {% if is_en %}Paste the code into the admin form and confirm the connection.{% else %}Вставьте код в форму админки и подтвердите подключение.{% endif %}

{{ "Important details" if is_en else "Важные детали" }}

  • {% if is_en %}The token is stored per company, so each organization can have its own Yandex Disk connection.{% else %}Токен хранится отдельно для каждой компании, поэтому у каждой организации может быть своё подключение к Яндекс.Диску.{% endif %}
  • {% if is_en %}The token is encrypted before saving.{% else %}Перед сохранением токен шифруется.{% endif %}
  • {% if is_en %}If the connection stops working, disconnect and reconnect the company from the same screen.{% else %}Если подключение перестало работать, отключите и снова подключите компанию на этой же странице.{% endif %}
